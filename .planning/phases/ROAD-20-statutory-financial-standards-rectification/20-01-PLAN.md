### Threat Model
- **T-20-01 (Statutory Inadmissibility of Rural Road Manual Citations)**: Citing rural road manual IRC:SP:20 Clause 14 for municipal urban highways exposes penalty show-cause notices and debarments to summary dismissal in civil writ petitions or arbitration. *Mitigation*: Replace all occurrences of "IRC:SP:20 Clause 14" with canonical "Contractual DLP Clause & Section 63/65B BSA 2023" referencing standard PWD/MORTH General Conditions of Contract (GCC) Clause 16/17 and evidentiary admissibility under Bharatiya Sakshya Adhiniyam (BSA) 2023.
- **T-20-02 (Treasury Audit Non-Compliance & Database Schema Breakage)**: PFMS vouchers citing commercial bank "Escrow" violate CAG guidelines and GFR 2017 Rule 171, which specify "Security Deposit (SD)" and "Retention Money". However, renaming database columns (`escrow_deposit_inr`, `escrow_holdback_released`) risks broken SQL queries, failed API contracts, or migration errors. *Mitigation*: Update voucher tokens to `PFMS/DLP-RETENTION/{YYYY}/{MMDD}-{HEX6}` while accepting legacy `DLP-ESCROW` in validation regex, update all user-facing UI copy and labels, while strictly preserving internal schema column names for zero-migration stability.
- **T-20-03 (Under-dimensioned Civil Engineering Volumetric Estimates)**: Estimating asphalt patching requirements using raw optical cavity dimensions ($V = \text{area} \times \text{depth}$) ignores real-world civil engineering practices specified in IRC:82. Unsquared perimeter edges and loose asphalt density lead to a ~26.5% material shortfall and inaccurate PWD SOR budget allocations. *Mitigation*: Codify IRC:82 rectangular saw-cut box trim margin (+15%, `saw_cut_margin_pct = 15.0`) and mechanical roller compaction allowance (+10%, `compaction_factor = 1.10`), combining to a $1.265\times$ volume factor, evaluated at 2.35 g/cm³ (2,350 kg/m³) bulk density and ₹68.0/kg PWD SOR rate in backend estimation logic and frontend 3D mesh visualizer.

     ```python
     def calculate_irc82_patch_estimate(
         cavity_area_m2: float,
         depth_cm: float,
         saw_cut_margin_pct: float = SAW_CUT_MARGIN_PCT,
         compaction_factor: float = COMPACTION_FACTOR,
         density_kg_l: float = ASPHALT_BULK_DENSITY_KG_L,
         rate_inr_per_kg: float = PWD_SOR_RATE_PER_KG
     ) -> dict:
         """
         Computes IRC:82 calibrated patch repair volume, asphalt mass, and PWD SOR 2025 repair cost.
         Formula:
           V_cavity = Area (m²) * Depth (m) * 1000 (L)
           V_patch  = V_cavity * (1 + saw_cut_margin / 100) * compaction_factor = V_cavity * 1.265
           Mass     = V_patch * 2.35 kg
           Cost     = Mass * ₹68.0
         """
         raw_vol_liters = cavity_area_m2 * (depth_cm / 100.0) * 1000.0
         trim_multiplier = 1.0 + (saw_cut_margin_pct / 100.0)
         patch_vol_liters = raw_vol_liters * trim_multiplier * compaction_factor
         asphalt_kg = patch_vol_liters * density_kg_l
         repair_cost_inr = asphalt_kg * rate_inr_per_kg

         return {
             "raw_cavity_liters": round(raw_vol_liters, 2),
             "patch_volume_liters": round(patch_vol_liters, 2),
             "asphalt_mass_kg": round(asphalt_kg, 1),
             "repair_cost_inr": round(repair_cost_inr, 0),
             "saw_cut_margin_pct": saw_cut_margin_pct,
             "compaction_factor": compaction_factor,
             "density_kg_l": density_kg_l,
             "rate_inr_per_kg": rate_inr_per_kg
         }
     ```
