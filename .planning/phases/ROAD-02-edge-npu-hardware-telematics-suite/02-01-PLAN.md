# Plan 02-01: Zero-Copy RKNN2 Pipeline & INT8 Quantized License Plate OCR

<planning_context>
### Objective
Transition RoadSaathi's vehicle perception subsystem from userspace memory churning and unquantized OCR models to a high-efficiency Rockchip RK3588 C++ zero-copy inference pipeline (`edge/rknn_pipeline.cpp`) and a lightweight two-stage INT8 ONNX license plate reader (`edge/anpr_onnx.py`). Hardware acceleration leverages DMA-BUF camera buffer mapping (`rknn_create_mem_from_fd`) and multi-core affinity scheduling to sustain >=30 FPS at <12W board power (EDGE-01), while providing a CPU/mock fallback for zero-hardware automated testing on Windows and x86 CI. The edge OCR engine enforces a strict 128MB ONNX session arena ceiling (<150MB total VRAM, EDGE-02), slot-aware MoRTH/HSRP syntax parsing with optical confusion matrix substitution, and DPDP Act 2023 salted hash compliance to safeguard citizen privacy.

### Scope Boundaries
- **In Scope:**
  - Bounded C-compatible struct `DetectionResult` and C-ABI export functions in `edge/rknn_pipeline.hpp`.
  - Dual-mode C++ engine in `edge/rknn_pipeline.cpp`: RKNN2 native on aarch64 (`librknn_api.so`), OpenCV/CPU deterministic fallback on x86_64 and Windows.
  - In-process Python ctypes shared object wrapper in `edge/rknn_wrapper.py` with struct memory alignment matching C++, core affinity configuration (`RKNN_NPU_CORE_0`, `RKNN_NPU_CORE_1`, `RKNN_NPU_CORE_2`, `RKNN_NPU_CORE_AUTO`), and pure-Python CPU mock fallback.
  - Two-stage INT8 ONNX plate reader in `edge/anpr_onnx.py`: 4-point perspective warp, CLAHE contrast enhancement, 128MB arena ceiling session configuration, MoRTH standard and Bharat series syntax regex parser with slot confusion substitution.
  - DPDP Act 2023 salted SHA-256 hash generation for routine corridor tracking and public-key encryption stub for statutory incident citations.
  - Refactoring `backend/app/services/anpr_engine.py` to use `edge.anpr_onnx` while maintaining backwards-compatible helper functions and deprecating unquantized EasyOCR PyTorch graphs.
  - Automated unit test suites in `edge/tests/test_rknn_pipeline.py` and `edge/tests/test_anpr_int8.py`.
- **Out of Scope:**
  - Cellular watchdog and offline store-and-forward ring buffer (deferred to Plan 02-02).
  - AIS-140 serial/socket packet parsing and 200ms IMU camera time-lock (deferred to Plan 02-02).
  - Contractor financial liability ledgers (IRC:SP:20 Clause 14) (Phase 3).
  - MapLibre WebGIS live video player and visualizer UI (Phase 4).

### Threat Model
- **T-02-01: RKNN2 C-ABI Memory Corruption & Missing Symbol Panics**: Native C/C++ libraries loaded via ctypes risk memory misalignment, buffer overruns, or unhandled symbol loading crashes on non-ARM platforms. Mitigated by explicit `#pragma pack(push, 1)` and `_pack_ = 1` ctypes field alignment, bounded string buffers (`char label[32]`), and graceful pure-Python CPU emulation fallback when `librknn_pipeline` binary is not found.
- **T-02-02: Edge OOM Exhaustion & Citizen PII Exposure (DPDP Act 2023)**: Running unquantized neural networks triggers OOM panics on 4GB/8GB SBCs sharing memory between GPU/NPU and OS. Furthermore, storing unhashed registration strings in plain text violates the Indian Digital Personal Data Protection Act 2023. Mitigated by static INT8 quantization, an explicit 128MB ONNX session arena cap (`session.max_arena_alloc_byte_limit = 134217728`), and salted SHA-256 hashing for routine corridor tracking.
</planning_context>

- edge/CMakeLists.txt (C++ shared library build configuration)

<action>
1. Create `edge/rknn_pipeline.hpp`:
   - Declare `#pragma pack(push, 1)` struct `DetectionResult`:
     ```cpp
     struct DetectionResult {
         int32_t class_id;
         float confidence;
         float box[4];       // [x1, y1, x2, y2] normalized 0.0 - 1.0
         float depth_cm;     // Estimated defect depth for D40
         float rpi_score;    // Calculated Road Pavement Index (0 - 100)
         int32_t is_p0;      // 1 = Critical Statutory Alert, 0 = Routine
         char label[32];     // Null-terminated string (e.g., "D40_POTHOLE")
     };
     ```
   - Declare C-compatible exports (`extern "C"` with `RS_EXPORT`):
     - `PipelineHandle rknn_pipeline_create(const char* model_path, int32_t target_core_mask, int32_t input_width, int32_t input_height);`
     - `int32_t rknn_pipeline_infer_dma(PipelineHandle handle, int32_t dma_fd, DetectionResult* out_results, int32_t max_results, int32_t* actual_count);`
     - `int32_t rknn_pipeline_infer_buffer(PipelineHandle handle, const uint8_t* bgr_data, int32_t width, int32_t height, DetectionResult* out_results, int32_t max_results, int32_t* actual_count);`
     - `void rknn_pipeline_destroy(PipelineHandle handle);`
2. Update `edge/rknn_pipeline.cpp`:
   - Implement the C exports defined in `rknn_pipeline.hpp`.
   - Implement dual-mode conditional compilation:
     - On ARM64 Linux with `librknn_api.so`: `#if defined(__aarch64__) && !defined(MOCK_RKNN) && defined(HAVE_RKNN_API)` binds `rknn_init`, `rknn_set_core_mask`, `rknn_create_mem_from_fd` for DMA-BUF zero-copy mapping.
     - On x86_64 / Windows or when `HAVE_RKNN_API` is unset: CPU mock fallback simulating inference detection results deterministically using OpenCV or synthetic generation.
3. Implement `edge/rknn_wrapper.py`:
   - Define `DetectionResultStruct(ctypes.Structure)` with `_pack_ = 1` matching C++ memory layout (size 56 bytes).
   - Implement dataclass `DetectionResult` for idiomatic Python consumption.
   - Implement `RKNNPipeline` class:
     - Loads `librknn_pipeline.so` (Linux) or `librknn_pipeline.dll` (Windows).
     - If the shared library is not found or fails to load, falls back gracefully to a pure-Python mock implementation (`MockRKNNPipeline`) providing deterministic responses without throwing `ImportError`.
     - Supports core affinity masks: `RKNN_NPU_CORE_AUTO = 0`, `RKNN_NPU_CORE_0 = 1`, `RKNN_NPU_CORE_1 = 2`, `RKNN_NPU_CORE_2 = 4`.
     - Exposes methods:
       - `infer_buffer(bgr_array: np.ndarray) -> List[DetectionResult]`
       - `infer_dma(dma_fd: int) -> List[DetectionResult]`
       - `close() -> None`
4. Implement `edge/tests/test_rknn_pipeline.py`:
   - `test_ctypes_struct_memory_alignment`: Asserts `ctypes.sizeof(DetectionResultStruct) == 56` and verifies field offset alignments (`class_id` at 0, `confidence` at 4, `box` at 8, `depth_cm` at 24, `rpi_score` at 28, `is_p0` at 32, `label` at 36).
   - `test_rknn_pipeline_mock_initialization`: Verifies `RKNNPipeline` creates and closes handles cleanly in mock environment.
   - `test_rknn_pipeline_infer_buffer_mock`: Passes a synthetic (640, 640, 3) BGR NumPy array through `infer_buffer` and verifies returned `DetectionResult` objects.
   - `test_rknn_pipeline_core_affinity_masks`: Asserts initialization succeeds across all core mask options (0, 1, 2, 4).
</action>

### Task 2: Two-Stage INT8 ONNX Plate OCR & MoRTH Syntax Engine
<name>Two-Stage INT8 ONNX Plate OCR & MoRTH Syntax Engine</name>
<read_first>
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-CONTEXT.md (Decisions D-05 through D-10)
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-RESEARCH.md (§3: Two-Stage INT8 Quantized License Plate OCR Pipeline)
- backend/app/services/anpr_engine.py (Existing ANPR engine implementation)
</read_first>
<action>
1. Implement `edge/anpr_onnx.py`:
   - Preprocessing utilities:
     - `rectify_plate_quadrilateral(image: np.ndarray, corners: Optional[np.ndarray] = None) -> np.ndarray`: Applies CLAHE (`clipLimit=2.5, tileGridSize=(8, 8)`) contrast normalization and 4-point perspective warp (`cv2.getPerspectiveTransform`, `cv2.warpPerspective`) into standard (128, 32) grayscale format.
   - `INT8ONNXPlateRecognizer`:
     - Initializes ONNX Runtime session with an explicit 128MB arena ceiling:
       - `session.max_arena_alloc_byte_limit = 134217728`
       - `enable_cpu_mem_arena = True`
       - `execution_mode = ort.ExecutionMode.ORT_SEQUENTIAL`
       - `intra_op_num_threads = 2`
     - Provides synthetic lightweight ONNX graph generation for zero-hardware unit tests when official weights are not mounted on the device.
   - `MoRTHSyntaxEngine`:
     - Strict regex validation:
       - Standard State / UT Plate: `^[A-Z]{2}[0-9]{1,2}[A-Z]{0,3}[0-9]{4}$`
       - Bharat Series (BH): `^[0-9]{2}BH[0-9]{4}[A-Z]{1,2}$`
     - Slot-aware optical confusion matrix substitution:
       - State code (Chars 0-1): Strictly Alpha (`0` -> `O`, `1` -> `I`, `8` -> `B`, `5` -> `S`).
       - RTO District code (Chars 2-3): Strictly Digit (`O` -> `0`, `I` -> `1`, `B` -> `8`, `S` -> `5`, `Z` -> `2`).
       - Vehicle series (Chars 4-5): Strictly Alpha (`0` -> `O` or `D`, `8` -> `B`, `1` -> `I`, `5` -> `S`).
       - Registration serial (Final 4): Strictly Digit (`O` -> `0`, `I` -> `1`, `B` -> `8`, `S` -> `5`, `Z` -> `2`).
   - `DPDPCryptographicVault`:
     - `hash_plate(plate: str, salt: str = "gcc_default_salt") -> str`: Computes salted SHA-256 hex digest for routine corridor tracking.
     - `encrypt_plate_incident(plate: str, public_key_pem: Optional[str] = None) -> str`: Encrypts raw plate string with Municipal Public Key (or mock RSA-OAEP / base64 envelope for CI) for confirmed statutory incident citations.
   - `PlateTrackCache`:
     - Per-track caching mechanism: Stores resolved plate string and confidence per vehicle `track_id` (confidence >= 0.85) to avoid redundant inferences on subsequent frames.
2. Refactor `backend/app/services/anpr_engine.py`:
   - Import and integrate `INT8ONNXPlateRecognizer`, `MoRTHSyntaxEngine`, and `DPDPCryptographicVault` from `edge.anpr_onnx`.
   - Update `ANPREngine.read_license_plate` to route through the INT8 ONNX pipeline and MoRTH syntax parser, replacing the heavy EasyOCR PyTorch execution graph.
   - Preserve public contracts: `INDIAN_STATE_CODES`, `NATIONAL_RTO_CODES`, `CHENNAI_RTO_CODES`, `parse_registration`, and return dictionary formats.
3. Implement `edge/tests/test_anpr_int8.py`:
   - `test_morth_standard_syntax_validation`: Tests valid Indian license plates (`TN01AB1234`, `MH12DE5678`, `DL04C1020`, `KA05MB9999`) against regex; asserts `is_valid == True`.
   - `test_bharat_series_syntax_validation`: Tests Bharat series format (`22BH1234AA`, `23BH9876ZZ`); asserts valid extraction of state code `BH`, year `22`, and registration number.
   - `test_optical_confusion_matrix_substitution`: Verifies that slot-based substitution repairs dirty characters:
     - State code: `0N01AB1234` -> `TN01AB1234`
     - RTO code: `TNIOAB1234` -> `TN10AB1234`
     - Series: `TN018B1234` -> `TN01BB1234`
     - Serial: `TN01ABIZ34` -> `TN01AB1234`
   - `test_dpdp_salted_hash_generation`: Asserts `hash_plate("TN01AB1234", salt="gcc_test_salt")` produces deterministic 64-character SHA-256 hex string and does not expose raw plate text.
   - `test_perspective_warp_and_clahe`: Validates that 4-point quadrilateral warp rectifies tilted image patches to horizontal (128, 32) aspect ratio.
   - `test_vram_memory_ceiling`: Asserts memory configuration of INT8 ONNX session enforces `max_arena_alloc_byte_limit = 134217728` (<150MB total VRAM ceiling).
</action>

- DPDP Act 2023 salted hash protects citizen PII in routine logs and telemetry.
- `backend/app/services/anpr_engine.py` functions without unbounded PyTorch EasyOCR memory allocation.
- `edge/tests/test_anpr_int8.py` passes all unit tests.
</acceptance_criteria>
