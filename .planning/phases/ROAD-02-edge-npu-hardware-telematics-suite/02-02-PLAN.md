# Plan 02-02: Cellular Reconnection Watchdog, Depot Wi-Fi Sync & AIS-140 Protocol

<planning_context>
### Objective
Provide edge resilience, store-and-forward telemetry preservation, and telematics hardware integration for transit fleet buses navigating cellular dead zones, physical road vibrations, and vehicle ignition cycles (EDGE-03). The system implements an asynchronous cellular watchdog thread with 5.0-second network polling and jittered backoff, a 50MB append-only JSONL ring buffer with atomic compaction, automated depot Wi-Fi burst sync for high-speed evidence offloading, and a priority-first reconnection flusher. Hardware telematics is unified through an official AIS-140 standard VLT packet parser (serial and TCP socket), 2nd-order Butterworth IMU vertical acceleration harmonic isolation with a 200ms camera time-lock to confirm statutory pothole impacts, an ultra-low-power sleep state machine (<1W) on vehicle ignition off, and Linux systemd hardware watchdog heartbeats.

### Scope Boundaries
- **In Scope:**
  - Asynchronous `CellularWatchdog` daemon thread running 5.0-second non-blocking TCP socket checks with randomized jitter backoff (1.0–3.0s).
  - Append-only `JsonlRingBuffer` writing to `edge_buffer_{bus_id}.jsonl` with atomic 50MB file compaction retaining the most recent 35MB.
  - Compressed WebP image snapshot FIFO spool directory (`spool/images/`) capped at 2GB with automatic disk quota eviction.
  - Priority-first queue flusher draining P0 critical incidents and live GPS coordinates before P1 routine road distress and P2 historical breadcrumbs.
  - Automated municipal depot burst sync triggered by authorized SSIDs (`GCC_DEPOT_WIFI_*`, `MTC_DEPOT_HIGHWAY_*`, `PMPML_DEPOT_5G`) or GPS geofence boundary (radius <= 150m).
  - Official AIS-140 standard packet parser (`edge/ais140_parser.py`) supporting RS-232 / USB serial (`/dev/ttyUSB0`) and TCP loopback mock socket (`127.0.0.1:9099`).
  - Dynamic rolling baseline IMU vertical acceleration calibration ($W=100$ samples) and 2nd-order Butterworth high-pass filter ($f_c = 0.8\text{ Hz}$, $f_s = 50\text{ Hz}$) isolating 15–40 Hz engine harmonics.
  - 200ms camera-IMU time-lock correlation ($g_z > 1.35g$ or $g_z < 0.75g$ within 200ms of optical camera detection) to classify `CONFIRMED_STATUTORY_DEFECT`.
  - Low-power vehicle sleep state machine (<0.8W) triggered when AIS-140 `ignition == False` for >60s, maintaining 10-minute cellular heartbeat and waking on ignition or tamper motion.
  - Unified orchestration in `edge/edge_agent.py` integrating watchdog, telematics parser, RKNN pipeline, and systemd watchdog (`sd_notify("WATCHDOG=1")`).
  - Automated unit and integration tests in `edge/tests/test_cellular_watchdog.py` and `edge/tests/test_ais140_telematics.py`.
- **Out of Scope:**
  - C++ RKNN2 zero-copy memory mapping and INT8 ONNX plate OCR (implemented in Plan 02-01).
  - Contractor financial penalty calculation and escrow liability ledger (Phase 3).
  - WebGIS origin-destination desire lines and live dashboard UI (Phase 4).

### Threat Model
- **T-02-03: Storage Wear-Out, Thread Deadlocks & Cellular Thundering Herd**: Continuously rewriting SQLite or JSON files destroys SBC flash memory within months. Furthermore, when hundreds of buses emerge from tunnels simultaneously, uncoordinated reconnection flushes overwhelm the municipal ICCC backend. Mitigated by append-only JSONL writes, atomic 35MB compaction swaps, lossy WebP image compression, randomized reconnection jitter (1.0–3.0s), and strict priority-tiered drain ordering (P0 before P1 before P2).
- **T-02-04: Telematics Packet Injection, Engine Harmonic False Positives & Vehicle Battery Depletion**: Corrupted or spoofed serial packets inject bogus telemetry, 15–40Hz diesel engine harmonics trigger hundreds of false pothole alerts, and leaving edge SBCs fully powered overnight drains the vehicle starter battery. Mitigated by strict AIS-140 checksum verification, 2nd-order Butterworth harmonic filtering coupled with a 200ms camera time-lock requirement, and automated low-power sleep (<1W) on ignition cutoff.
</planning_context>

### Task 1: Cellular Watchdog Loop, 50MB Ring Compaction & Depot Wi-Fi Burst Sync
<name>Cellular Watchdog Loop, 50MB Ring Compaction & Depot Wi-Fi Burst Sync</name>
<read_first>
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-CONTEXT.md (Decisions D-11 through D-14)
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-RESEARCH.md (§4: Cellular Watchdog & Offline Store-and-Forward)
- edge/edge_agent.py (Current edge agent persistence and networking logic)
</read_first>
<action>
1. Implement `edge/cellular_watchdog.py`:
   - `CellularWatchdog`:
     - Daemon thread evaluating network liveness every 5.0 seconds using non-blocking TCP socket checks (`socket.create_connection`) to the central gateway host:port (timeout 1.5s).
     - Maintains atomic `is_online` status boolean.
     - Implements connection state callbacks (`on_disconnect`, `on_reconnect`) with randomized jitter backoff (1.0–3.0 seconds) to prevent thundering herd flushes across fleet buses.
   - `JsonlRingBuffer`:
     - Manages `edge_buffer_{bus_id}.jsonl` using append-only writes to protect SBC eMMC/SD storage from wear.
     - Atomic 50MB compaction: Checks file size; when size exceeds 50MB (~50,000 pings), reads records and writes the latest 35MB of lines to `edge_buffer_{bus_id}.jsonl.tmp`, then executes `os.replace` for atomic file replacement.
   - `ImageSpoolManager`:
     - Stores forensic road hazard image snapshots as compressed WebP files (quality 75, ~30KB) under `spool/images/{timestamp}_{uuid}.webp`.
     - Maintains disk cap (default 2GB); when spool usage exceeds 90% (1.8GB), evicts oldest non-P0 images in FIFO order.
   - `PriorityReconnectionFlusher`:
     - On network reconnection, sorts buffered records into 3 priority tiers:
       - **Tier 0 (P0)**: Critical statutory defects (`D40_POTHOLE` with IMU lock, `OPEN_MANHOLE`, active MVA violations) and current live GPS coordinates, dispatched immediately.
       - **Tier 1 (P1)**: Routine road distresses (`D20_CRACK`, surface ravelling, crosswalk logs).
       - **Tier 2 (P2)**: Historical breadcrumb GPS pings, flushed in background batches of 50 records with 500ms pacing.
   - `DepotBurstSync`:
     - Detects depot presence via Wi-Fi SSID inspection (prefixes: `GCC_DEPOT_WIFI_*`, `MTC_DEPOT_HIGHWAY_*`, `PMPML_DEPOT_5G`) or GPS distance to configured depot coordinates ($R \le 150\text{m}$).
     - On detection, triggers high-speed concurrent burst upload of forensic WebP images and full telemetry logs to `/api/v1/fleet/edge-sync`.
2. Implement `edge/tests/test_cellular_watchdog.py`:
   - `test_cellular_watchdog_5sec_polling`: Mocks TCP socket connection and verifies watchdog detects connection drop and reconnection within 5.0-second intervals.
   - `test_append_only_ring_buffer_write_and_read`: Writes 500 simulated telemetry records to a test JSONL buffer; verifies records are valid JSON and read without formatting corruption.
   - `test_ring_buffer_50mb_compaction`: Simulates a file exceeding 50MB; verifies atomic compaction trims to ~35MB and leaves valid JSONL lines.
   - `test_priority_reconnection_upload_order`: Populates buffer with mixed P0, P1, and P2 telemetry records; asserts that upon reconnection, all P0 records are dispatched strictly before P1 and P2 records.
   - `test_webp_image_spool_cap_eviction`: Creates mock snapshots exceeding the 2GB cap; asserts FIFO pruning removes oldest non-P0 files while preserving P0 incident snapshots.
   - `test_depot_burst_sync_trigger`: Tests trigger logic against mock depot SSIDs and GPS geofence boundary coordinates.
</action>
<acceptance_criteria>
- Cellular watchdog evaluates network liveness every 5.0 seconds without blocking inference loops.
- JSONL ring buffer caps file size at 50MB with atomic swap without data corruption.
- Priority-first flusher guarantees critical P0 alerts and current live coordinates are transmitted before routine breadcrumbs.
- Depot burst sync activates high-speed offload on depot SSID or geofence arrival.
- `edge/tests/test_cellular_watchdog.py` passes all unit tests.
</acceptance_criteria>

### Task 2: AIS-140 Telematics Parser, 200ms IMU Time-Lock & Edge Agent Integration
<name>AIS-140 Telematics Parser, 200ms IMU Time-Lock & Edge Agent Integration</name>
<read_first>
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-CONTEXT.md (Decisions D-15 through D-18)
- .planning/phases/ROAD-02-edge-npu-hardware-telematics-suite/02-RESEARCH.md (§5: Hardware Telematics & AIS-140 Protocol)
- edge/edge_agent.py (Current edge agent daemon implementation)
</read_first>
<action>
1. Implement `edge/ais140_parser.py`:
   - `AIS140Packet` dataclass:
     - `imei: str`, `timestamp: datetime`, `gps_fix: bool`, `latitude: float`, `longitude: float`, `speed_kmh: float`, `heading: float`, `ignition: bool`, `panic_button: bool`, `vertical_accel_g: float`, `battery_voltage: float`, `tamper_status: bool`.
   - `AIS140Parser`:
     - Parses standard AIS-140 `$PV` sentence protocol and NMEA strings (`$GPRMC`, `$GPGGA`).
     - Validates sentence checksums (XOR checksum verification between `$` and `*`).
     - Supports streaming from RS-232 / USB serial (`/dev/ttyUSB0` at 115200 baud) and loopback TCP mock socket (`127.0.0.1:9099`) for zero-hardware automated tests.
   - Digital signal processing for vertical acceleration:
     - 2nd-order digital high-pass Butterworth filter ($f_c = 0.8\text{ Hz}$, $f_s = 50\text{ Hz}$) with coefficients ($b_0 = 0.9314, b_1 = -1.8628, b_2 = 0.9314, a_1 = -1.8592, a_2 = 0.8665$) filtering 15–40 Hz engine combustion harmonics.
     - Dynamic rolling baseline calibration: Continuously calculates rolling average over 2.0s sliding window ($W=100$ samples at 50Hz) to track vehicle pitch and passenger load drift.
     - 200ms camera-IMU time-lock correlation:
       - When optical camera registers severe pothole (`D40`, depth >= 7.5cm) at $t_{\text{cam}}$, opens window $[t_{\text{cam}}, t_{\text{cam}} + 200\text{ms}]$.
       - Verifies vertical acceleration deviation ($g_z > 1.35g$ suspension strike or $g_z < 0.75g$ cavity drop).
       - Classifies into: `CONFIRMED_STATUTORY_DEFECT` (optical + IMU shock within 200ms), `OPTICAL_PRELIMINARY` (optical only), or `MECHANICAL_UNCLASSIFIED` (IMU shock only).
2. Refactor and unify `edge/edge_agent.py`:
   - Integrates `RKNNPipeline` (from `edge/rknn_wrapper.py`), `INT8ONNXPlateRecognizer` (from `edge/anpr_onnx.py`), `CellularWatchdog` & `JsonlRingBuffer` (from `edge/cellular_watchdog.py`), and `AIS140Parser` (from `edge/ais140_parser.py`).
   - Vehicle power state machine:
     - When AIS-140 reports `ignition == False` continuously for >60 seconds:
       - Suspends camera capture and releases V4L2 device.
       - Puts NPU inference into sleep state.
       - Transitions edge agent into ultra-low-power mode (<0.8W), emitting a minimal 120-byte heartbeat ping every 10 minutes.
     - Resumes full 30 FPS scanning within 1.2 seconds when `ignition == True` or when tamper accelerometer registers $>0.2g$.
   - Linux systemd watchdog heartbeat:
     - Implements `notify_systemd_watchdog()` sending `b"WATCHDOG=1"` to `$NOTIFY_SOCKET` every 15 seconds to prevent system supervisor timeouts.
3. Implement `edge/tests/test_ais140_telematics.py`:
   - `test_ais140_packet_decoding`: Ingests standard AIS-140 `$PV` sentence; validates parsed IMEI, GPS coordinates, speed, heading, ignition status, and panic SOS button with checksum check.
   - `test_imu_rolling_baseline_calibration`: Feeds synthetic 50Hz accelerometer stream with 1.0g gravity baseline + gradual vehicle pitch; asserts dynamic baseline tracks drift.
   - `test_imu_butterworth_vibration_isolation`: Feeds 25Hz engine vibration harmonic alongside a 5Hz pothole impact spike; verifies filter eliminates the 25Hz noise while preserving the shock transient.
   - `test_imu_camera_200ms_timelock_positive`: Simulates optical camera pothole detection at $t=1000\text{ms}$ and vertical acceleration shock ($1.52g$) at $t=1120\text{ms}$ ($\Delta t = 120\text{ms} < 200\text{ms}$); asserts `CONFIRMED_STATUTORY_DEFECT` status is generated.
   - `test_imu_camera_200ms_timelock_negative`: Simulates optical camera detection at $t=1000\text{ms}$ and shock at $t=1450\text{ms}$ ($\Delta t = 450\text{ms} > 200\text{ms}$); asserts optical candidate is downgraded to `OPTICAL_PRELIMINARY`.
   - `test_low_power_sleep_state_machine`: Sends AIS-140 packet with `ignition = False`; verifies edge agent enters low-power sleep mode, suspends frame capture, and throttles heartbeat to 10-minute interval.
</action>
<acceptance_criteria>
- AIS-140 parser accurately decodes serial and socket packets with checksum validation.
- IMU Butterworth filter and 200ms time-lock isolate true road shocks from engine vibrations.
- Edge agent manages sleep/wake power states based on vehicle ignition status.
- `edge/tests/test_ais140_telematics.py` passes all unit tests.
</acceptance_criteria>
