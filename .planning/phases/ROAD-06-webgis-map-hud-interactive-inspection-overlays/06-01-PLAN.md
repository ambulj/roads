# Plan 06-01: WebGIS Map Floating Dock, Cluster Inspection Popups, and Layer Panel Polish

<planning_context>
### Objective
Modernize RoadSaathi's primary WebGIS command center into a cohesive, high-performance spatial HUD. Replace disconnected controls with a floating glassmorphic map control dock featuring smooth animated corridor jumps, deliver high-contrast cluster inspection popup cards with 1-click RPI mathematical explainers, and implement a streamlined zero-flicker layer visibility menu for all 6 analytical GIS overlays.

### Scope Boundaries
- **Floating Map Control Dock**: Anchor top-center/right with `backdrop-blur-md bg-white/90 dark:bg-slate-900/90 border border-slate-200/80 dark:border-slate-800/80 shadow-float rounded-2xl`. Incorporate 5 quick corridor jump pills (GST Road, Kathipara Cloverleaf, OMR IT Expressway, Anna Salai CBD, Central Station Link) animated via `map.flyTo()`, a compass heading/pitch reset button, basemap mode switcher, and split-view/telemetry drawer toggles. Ensure horizontal overflow protection on mobile viewports (< 768px).
- **High-Contrast Cluster Inspection Popup Cards**: Render accessible, rich forensic popup cards on defect pin clicks with defect code badges (`D40 Pothole`, `D20 Alligator Crack`), pass consensus counts, color-coded RPI score pills (P0 Critical / P1 High / P2 Routine), and direct 1-click trigger to [`RPIFormulaModal.tsx`](file:///c:/Users/sauja/Downloads/roads/frontend/src/components/modals/RPIFormulaModal.tsx) pre-populated with active defect parameters.
- **Streamlined Layer Visibility Menu**: Organize the 6 analytical layers (Defect Clusters, Live Transit Fleet, PS 26124 OD Desire Lines, Monsoon Flood Contours, Sensitive POIs, and Traffic Bottlenecks) into a clean dropdown with active layer count badge, applying visibility toggles via MapLibre `setLayoutProperty('visibility')` without WebGL context destruction.

### Threat Model & UI Boundaries
- **T-06-01 (WebGL Context Loss on Layer Toggle)**: Never recreate MapLibre map instances or source layers on toggle; update layer visibility flags or GeoJSON source data reactively.
- **T-06-02 (Mobile Viewport HUD Overflow)**: The floating HUD dock and inspection cards must adapt responsively on smaller mobile screens (< 768px) using flexible wrapping, compact padding, and horizontal scrollbars.
- **T-06-03 (Desynchronized RPI Modal State)**: Ensure clicking "Inspect RPI Formula" from map popups cleanly passes the full `HazardCluster` payload to `onSelectCluster` before triggering `onOpenRPIModal`.
</planning_context>
