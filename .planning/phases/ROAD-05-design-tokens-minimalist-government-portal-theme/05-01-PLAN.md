# Plan 05-01: Civic Design Tokens, Theme Engine & Global Navigation Polish

<planning_context>
### Objective
Establish the modern, high-contrast, accessible government civic command center theme for RoadSaathi. Unify design tokens across CSS custom properties, Tailwind CSS configuration, theme context persistence, and global navigation layouts into a sleek minimalist aesthetic that enhances data legibility for municipal engineers, civic administrators, and judicial reviewers.

### Scope Boundaries
- Replace legacy serif CSS font stacks with modern sans-serif (`Inter`, `Source Sans 3`) and monospaced telemetry fonts (`JetBrains Mono`).
- Enforce fixed-figure numerical formatting (`tabular-nums` and `.telemetry-mono`) to prevent layout jitter on real-time 5Hz sensor streams.
- Standardize light (WCAG AAA `#F8FAFC` / `#FFFFFF` / Deep Indigo `#4338CA`), dark (Obsidian `#0B0F19` / `#111827` / Indigo `#6366F1`), and cyber edge palettes.
- Polish `ThemeContext.tsx` zero-flicker persistence and `ThemeToggle.tsx` visual feedback.
- Restructure `SidebarNav.tsx` to the two-tier municipal hierarchy (*Tier 1: On-Bus Edge Perception* and *Tier 2: Civic Command & Governance*) with active indigo left-border indicators.

### Threat Model & UI Boundaries
- **T-05-01 (CSS Variable Cascade Bleed & Hardcoded Colors)**: Avoid hardcoded hex colors in child components; always consume Tailwind semantic utility classes or CSS custom properties.
- **T-05-02 (Theme Toggle White Flash / Flicker)**: Persist user preference to `localStorage` and ensure `<html>` classList synchronization without unstyled flashes or broken contrast.
</planning_context>
