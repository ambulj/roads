# Plan 07-01: Executive Dashboard Scorecards, Contractor SLA Action Console & Backlog Data Tables Polish

<planning_context>
### Objective
Elevate the RoadSaathi municipal command suite into an executive-grade command portal for civic authorities, PWD highways engineers, and municipal executives (GCC, MoHUA, NHAI). Modernize the executive KPI scorecards with animated SVG progress gauges and tabular monospace numerals, deliver an interactive 3-tab Contractor SLA action console with multi-pass concurrence payment clearance gating ($|g_z - 1.0| < 0.15g$), and polish the work orders backlog data tables with sticky headers, multi-column sorting, and 1-click CSV export controls.

### Scope Boundaries
- **Executive KPI Scorecards & Fleet Health** (`MetricCards.tsx`, `CommandCenter.tsx`, `Analytics.tsx`): 5 high-density scorecard tiles (Active Edge Buses, 15m DBSCAN Clusters, Traffic Incidents, Active PWD Work Orders, Life-Safety Hazards) featuring animated SVG circular progress gauges, trend micro-badges (`+12.4% vs last week`, `99.2% on-time SLA`), tabular monospace numbers (`font-mono tabular-nums`), and WCAG AAA contrast ($\ge 7:1$).
- **Interactive 3-Tab Contractor SLA Action Console** (`WorkOrderActionConsole.tsx`):
  - **Tab 1: CAD & Defect Audit**: Interactive before/after split slider, 5-pass optical & IMU evidence gallery, and engineering volumetric material calculator (DBM VG-30 kg, SOR 2025 rates, IRC:SP:20 Clause 14).
  - **Tab 2: Contractor Assignment & SLA**: Agency CIN & Project Director details, escrow security deposit balance, debarment risk meter, and direct WhatsApp dispatch with pure SVG QR code generator.
  - **Tab 3: Multi-Pass Concurrence & Payment Release**: Real-time 3-pass dual-sensor cards (`bus_id`, timestamp, vertical IMU $g_z$), with the `"Authorize Payment & Release Escrow"` CTA strictly disabled with tooltip until $\ge 3$ distinct transit bus passes verify smooth surface condition ($|g_z - 1.0| < 0.15g$).
- **Contractor Escrow & Auto-Debit Ledger** (`ContractorSlaLedger.tsx`): High-contrast summary metrics, 1-click IRC:SP:20 Clause 14 auto-debit trigger calling `/api/contractors/penalties/auto-debit` upon simulated $1.48g$ recurrence shock, and dual-view toggle between Performance SLA Table and Auto-Debit Audit Docket.
- **Accessible Work Order Backlog & Data Tables** (`WorkOrders.tsx`): Sticky header data table with multi-column sorting (RPI score, SLA countdown, corridor, status), instant filter chips, and 1-click CSV export (`/api/work-orders/export/csv`).

### Threat Model & UI Boundaries
- **T-07-01 (Layout Shifts & Text Jitter on 5Hz Sensor Updates)**: Use fixed pixel dimensions for SVG gauge rings and enforce `font-mono tabular-nums` across all counters and monetary values to eliminate jitter during real-time telemetry streaming updates.
- **T-07-02 (Desynchronized Action Console & Backlog State)**: Ensure work order status updates inside `WorkOrderActionConsole.tsx` trigger parent state reconciliation via `requestStatusUpdate` and surface instantaneous toast confirmations.
- **T-07-03 (Accidental Escrow Release Violation)**: Strictly guard payment clearance CTA button in Tab 3 by requiring $N \ge 3$ distinct verified transit fleet passes within tolerance $|g_z - 1.0| < 0.15g$, disabling the button with clear explanatory tooltip when criteria are unmet.
</planning_context>

     ```tsx
     const SvgProgressRing: React.FC<{
       percentage: number;
       colorClass: string;
       bgClass: string;
       size?: number;
       strokeWidth?: number;
     }> = ({ percentage, colorClass, bgClass, size = 38, strokeWidth = 3.5 }) => {
       const radius = (size - strokeWidth) / 2;
       const circumference = 2 * Math.PI * radius;
       const clamped = Math.min(100, Math.max(0, percentage));
       const strokeDashoffset = circumference - (clamped / 100) * circumference;

       return (
         <div className="relative flex items-center justify-center shrink-0" style={{ width: size, height: size }}>
           <svg width={size} height={size} className="transform -rotate-90">
             <circle
               cx={size / 2}
               cy={size / 2}
               r={radius}
               stroke="currentColor"
               strokeWidth={strokeWidth}
               fill="transparent"
               className={bgClass}
             />
             <circle
               cx={size / 2}
               cy={size / 2}
               r={radius}
               stroke="currentColor"
               strokeWidth={strokeWidth}
               fill="transparent"
               strokeDasharray={circumference}
               strokeDashoffset={strokeDashoffset}
               strokeLinecap="round"
               className={`${colorClass} transition-all duration-700 ease-out`}
             />
           </svg>
         </div>
       );
     };
     ```
