# 09-01-PLAN: WebGIS Top Micro-Dock, Collapsible Bottom HUD Trays, and Single-Line Triage Filter Strip

<planning_context>
### Objective
Maximize primary WebGIS viewport real estate and declutter the spatial command center. Condense top telemetry and filters into a unified 44px single-line executive bar with an on-demand collapsible `MetricCards` accordion (gaining ~120px vertical canvas height). Support collapsing the right-side triage dock into a 44px vertical icon rail (enabling 100% widescreen map expansion with zero WebGL context recreation). Refactor intrusive floating map cards into sleek slide-up bottom analytical trays docked cleanly above the map legend with minimize/close controls, and streamline the top WebGIS control bar into a minimalist micro-dock capsule.

### Scope Boundaries
- **In-Scope**:
  1. `CommandCenter.tsx`:
     - Merge quick search, live KPI telemetry badges (Fleet, Hazards, Incidents), status selector, severity selector, reset button, and KPI Grid toggle into a unified 44px (`h-11`) single-line bar.
     - Implement collapsible accordion container for `MetricCards.tsx` (collapsed by default, smooth CSS height transition).
     - Implement collapsible right dock state (`isDockCollapsed`): 44px vertical icon rail (with queue counter badge and inspector quick-select) vs 380px full pane.
     - Ensure `map.resize()` is triggered smoothly via `ResizeObserver` without WebGL context loss or canvas flicker.
  2. `PriorityQueue.tsx` & `OperatorInspectorPanel.tsx`:
     - Fluid responsive padding and compact header sizing that adapt gracefully when right dock width changes or when rendered in mobile drawer mode.
  3. `WebGISMap.tsx`:
     - Streamline top floating control dock into a compact micro-dock capsule containing horizontally scrollable corridor pills, compass reset, basemap switcher, and 10-layer analytical dropdown with click-outside protection.
     - Convert floating OD transit flow matrix overlay and Municipal Blind Spots banner into docked slide-up bottom analytical trays above the legend.
     - Add interactive Corridor Elevation & Roughness Profile slide-up tray with chainage milestones and IRI rating.
     - Provide collapse/expand toggles (`ChevronDown`/`ChevronUp`) and close buttons (`X`) on all bottom analytical trays.
- **Out-of-Scope**:
  - Global navigation sidebar restructuring (completed in Phase 8).
  - Tabbed executive analytics redesign in `Analytics.tsx` and compact work order table cells in `WorkOrders.tsx` (handled in Phase 10).

### Threat Model & Risk Mitigations
- **T-09-01 (WebGL Context Loss & Canvas Flicker)**:
  *Risk*: Changing parent flex container dimensions during top HUD collapse or right dock collapse could unmount MapLibre or trigger canvas recreation.
  *Mitigation*: Maintain MapLibre instance in persistent `mapRef.current` without conditional re-renders. Use CSS transitions on parent flex containers and rely on the active `ResizeObserver` in `WebGISMap.tsx` to call `map.resize()` smoothly on animation frames.
- **T-09-02 (Z-Index Collisions & Visual Overlap)**:
  *Risk*: Slide-up bottom analytical trays overlapping the bottom legend, micro-dock dropdown, or right triage dock.
  *Mitigation*: Standardize z-index hierarchy: Base map (`z-0`), bottom legend (`z-10`), slide-up bottom analytical trays docked at `bottom-12 left-3 max-w-lg z-20`, top micro-dock capsule (`z-30`), layers dropdown (`z-50`), and right dock (`z-10`/`z-20`).
- **T-09-03 (Filter & Telemetry State Inconsistency)**:
  *Risk*: Collapsing `MetricCards` might disconnect live telemetry numbers or break real-time cluster/incident filtering.
  *Mitigation*: Keep live KPI counters (Fleet, Hazards, Incidents) persistently rendered in the single-line top bar, while the accordion only toggles the expanded 5-card detailed scorecard view.
</planning_context>
