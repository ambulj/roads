# Plan 15-01: RoadSaathi Civic Copilot & Natural Language Intelligence

<planning_context>
### Objective
Equip municipal commanders, traffic enforcement officers, and PWD engineers with a high-performance, natural language conversational assistant to query fleet telemetry, audit contractor SLA breaches, inspect road hazard hotspots, and automate statutory show-cause notice drafting without writing manual SQL or navigating complex filter menus, fulfilling Milestone `v5.0` and Requirements `COPILOT-01` and `COPILOT-02`:
1. **Deterministic Semantic Query Dispatcher (COPILOT-01, D-15-01)**:
   - Implement a schema-aware, deterministic query engine in `backend/app/services/copilot_engine.py` and API router in `backend/app/api/endpoints/copilot.py` mounted at `/api/copilot/query`.
   - Run 100% locally on the FastAPI backend over SQLite WAL and PostgreSQL 16 schemas with sub-10ms response latency, eliminating mandatory cloud LLM subscriptions or external API keys.
   - Deterministic classification across 5 municipal intents: `DEFECT_QUERY`, `CONTRACTOR_AUDIT`, `CORRIDOR_SAFETY_RANKING`, `STATUTORY_NOTICE_DRAFT`, and `GENERAL_HELP_GUIDE`.
   - Schema-aware entity extraction covering known corridors (`GST Road`, `OMR`, `Anna Salai`, `Inner Ring Road`, `Kathipara`), contractors (`L&T`, `GMR`, `TNRDC`, `HCC`, `Chettinad`), defect severity (`P0`, `P1`, `P2`), and hazard categories (`pothole`, `crack`, `manhole`, `waterlogging`).
2. **Floating Slide-Over Civic Copilot Drawer & Global Shortcut (COPILOT-02, D-15-02)**:
   - Build a responsive slide-over drawer component in `frontend/src/components/copilot/CivicCopilotDrawer.tsx` accessible globally in `frontend/src/App.tsx` across the Command Center and Work Orders workspaces.
   - Anchor a high-contrast Floating Action Button (FAB) at `fixed bottom-6 right-6 z-40` with an animated bot/sparkle icon and keyboard badge.
   - Bind `Ctrl + K` (Windows/Linux) and `Cmd + K` (macOS) to toggle the Copilot drawer and automatically focus the query input; remap CommandPalette to `Ctrl + Shift + K` and `Ctrl + P`.
   - Provide one-click municipal prompt chips (*"Show unaddressed P0 potholes on GST Road"*, *"Contractors with highest SLA breaches"*, *"Corridors with worst road condition"*, *"Draft Form 14 notice for L&T breaches"*).
3. **Actionable Civic Cards & 1-Click Deep Links (COPILOT-02, D-15-03, D-15-04)**:
   - Present query results with an executive summary followed by structured entity cards displaying tabular metrics (RPI score, breach counts, escrow balances, penalty amounts).
   - Provide interactive action triggers:
     - **Fly to on Map**: Teleports WebGIS camera viewport (`lat`, `lng`, `zoom`) and highlights the cluster/corridor.
     - **Inspect in Backlog**: Deep links to the CAD Backlog table and filters by ticket code.
     - **View Ledger**: Deep links to the Contractor SLA Financial Ledger.
     - **Draft Form 14 Notice**: Assembles an evidentiary packet under IRC:SP:20 Clause 14 and BSA 2023 Section 63/65B (SHA-256 evidence hash, 7-day cure window deadline, statutory penalty amount), navigates to Work Orders SLA tab, and pre-fills the `ContractorSlaLedger.tsx` Form 14 Show-Cause Notice Pack Modal via application event `roadsaathi:open-form14`.
4. **Comprehensive Automated Test Battery & Regression Invariant (COPILOT-01, COPILOT-02)**:
   - Author `backend/tests/test_copilot_engine.py` covering all 5 intents, entity extraction, boundary edge cases, and statutory Form 14 payload generation.
   - Preserve 100% pass rate across the existing 44-test core statutory/physics suite and 117-test full backend test suite.
   - Verify `npm --prefix frontend run build` completes with 0 TypeScript diagnostics and clean Vite bundle output.

### Threat Model
- **T-15-01: Hallucination & Non-Deterministic Action Risk in Municipal Operations**:
  - *Risk*: A generative AI assistant might invent fictitious road defects, hallucinate contractor liability amounts, or trigger unauthorized financial debits.
  - *Mitigation*: The semantic query engine is 100% deterministic, utilizing regex-driven intent classification and parameterized SQLAlchemy queries over real database tables (`distress_clusters`, `contractors`, `contractor_penalties`). Statutory notice drafting generates a structured payload requiring manual Executive Engineer review and cryptographic digital sign-off in `ContractorSlaLedger.tsx` before statutory notice issuance.
- **T-15-02: Keyboard Shortcut Collision & Accessibility Lockout**:
  - *Risk*: `Ctrl+K` was previously bound to `CommandPalette`. Overriding it without coordination causes race conditions where both modals open or trap focus, creating keyboard accessibility violations.
  - *Mitigation*: `Ctrl+K` / `Cmd+K` is cleanly bound to toggle `CivicCopilotDrawer`. `CommandPalette` is remapped to `Ctrl+Shift+K` and `Ctrl+P`. The drawer implements ARIA semantics (`role="dialog"`, `aria-label="Civic Copilot"`), autofocuses the query input on open, and closes cleanly on `Escape` key without leaking listeners.
- **T-15-03: Statutory Evidentiary Inadmissibility in Notice Drafting**:
  - *Risk*: Notices drafted via natural language could omit essential statutory components mandated by BSA 2023 Section 63/65B or IRC:SP:20 Clause 14, rendering them vulnerable to judicial challenge or arbitral stay.
  - *Mitigation*: The `STATUTORY_NOTICE_DRAFT` handler links directly to `contractor_service.py`, computing the immutable SHA-256 evidence hash (`compute_statutory_evidence_hash`), adhering to the statutory penalty schedule (₹25k 1st recurrence, ₹50k 2nd, ₹100k + GeM debarment warning 3rd+), formatting official docket numbers (`FORM-14/DLP/{YYYY}/{CLUSTER_CODE}`), and enforcing the mandatory 7-day cure window deadline.
